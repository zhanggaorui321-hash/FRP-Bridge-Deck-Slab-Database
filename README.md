# FRP Bridge-Deck Slab Database

This repository provides the supporting evidence register and experimental
datasets for the review:

**Concrete Bridge-Deck Slabs Internally Reinforced with FRP Bars:
State of the Art and Research Needs**

## Repository Contents

### Experimental_Evidence_Register.docx
Publication-level evidence register documenting the experimental and field
studies included in the review and their roles in the evidence synthesis.

### FRP_Reinforced_Concrete_Slab_Shear_Database.xlsx
Source-traceable experimental database supporting the one-way shear
parameter analyses and model comparisons presented in Figs. 7–9.

### FRP_Bridge_Deck_Test_Database.xlsx
Experimental database supporting the synthesis of the structural behavior
of internally FRP-reinforced concrete bridge-deck slabs.

## Data Traceability

The datasets document the provenance of the experimental records, specimen
identification, publication overlap, and the eligibility of individual
records for quantitative analysis.

If these datasets are used, please cite the associated review article.
